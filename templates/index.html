Application Architecture & Request Flow

Designed for Cloud Computing deployment on Google Cloud Run

1

Client Submission

User enters applicant features into the dashboard. Frontend validates fields and sends a POST /predict request.

2

Flask API & Validation

Flask backend receives payload, generates a unique Request ID, validates data types, and checks constraints.

3

Scikit-Learn Pipeline

Input passes through preprocessor (Median/Frequent Imputation, StandardScaler, OneHotEncoder) and Logistic Regression model.

4

Sanitized Cloud Logging

Outputs prediction verdict, confidence, duration, and status to stdout for Google Cloud Logging, avoiding PII leakage.
